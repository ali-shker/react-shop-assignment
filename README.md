# React Shop Assignment

Luma Market is a small React shopping application built to demonstrate the core concepts from a React.js assignment:

- JSX and reusable components
- Props, `useState`, `useEffect`, and `useContext`
- Redux global state for the shopping bag
- React Router with Home, Products, Cart, and About routes
- Fake Store API product fetching
- Search, category filtering, conditional rendering, and responsive styling
- A pretend checkout form with validation and submission feedback

## Run locally

```bash
pnpm install
pnpm --filter @workspace/react-shop-assignment run dev
```

The main app lives in `artifacts/react-shop-assignment`.
